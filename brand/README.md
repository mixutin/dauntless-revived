# Brand assets

The logo and emblem are the project's own artwork, made for Dauntless Revived by mixutin: they
contain no Phoenix Labs art, and the repository's licence is unchanged.

Everything in this folder except the two masters, `palette.json`, `build.py` and this file is
generated by `build.py`. Edit the masters or the script, never the generated images.

## Palette

Measured from the pixels of `logo-full.png`. These eight colours are the whole palette. Each project
(docs site, launcher, images) defines them once as tokens under these names, for example `--dr-ink`
in CSS, and uses the tokens everywhere else. The same values are in `palette.json` for scripts.

| Token | Hex | Role |
| --- | --- | --- |
| `ink` | `#01090D` | Page background |
| `navy` | `#031523` | Surface: sidebar, cards, code blocks, header |
| `deep` | `#093251` | Raised surface, borders between surfaces |
| `azure` | `#0D669C` | Dark accent: hover and pressed fills, control borders on `ink` |
| `ice` | `#18A7E0` | Primary accent: links, primary buttons |
| `glow` | `#78ECF9` | Highlights, hovered links, focus rings, small glows |
| `steel` | `#999FA7` | Muted text: captions, metadata, footers |
| `frost` | `#F3F4F5` | Body text and headings |

### Contrast (WCAG 2.2)

AA needs 4.5:1 for normal text, and 3:1 for large text, UI components and focus indicators.

| Text or UI colour | on `ink` | on `navy` | on `deep` | Use |
| --- | --- | --- | --- | --- |
| `frost` | 18.23 | 16.80 | 12.02 | Body text, headings |
| `steel` | 7.52 | 6.93 | 4.96 | Muted text |
| `ice` | 7.31 | 6.73 | 4.82 | Links |
| `glow` | 14.50 | 13.36 | 9.56 | Hovered links, highlights, focus rings |

Buttons and fills:

- Primary button: `ink` text on `ice`, 7.31. On hover, `ink` on `glow`, 14.50.
- Pressed or secondary fill: `frost` text on `azure`, 5.61.
- Control borders: `azure` on `ink` (3.25) passes 3:1, but `azure` on `navy` (2.99) does not, so
  inputs on a `navy` surface use a `steel` border (6.93).

Pairs that fail, so do not use them:

- White or `frost` text on `ice` (2.75 and 2.50). This is why primary buttons use dark text.
- `azure` as normal-size text (3.25 on `ink`). Large text and borders only.
- `deep` as the only edge of a control (1.52 on `ink`). It is for dividers between surfaces.
- `ice` or `steel` text on an `azure` fill (2.25 and 2.32).

`python3 brand/build.py --check` recomputes every ratio in `palette.json` and fails if one is out of
date or below its requirement. It also fails if the docs site's tokens or its image copies (below)
no longer match.

### The docs site

GitHub Pages serves only `docs/`, so `build.py` copies what the site uses into `docs/assets/`:
`favicon.ico`, `icon-192.png`, `apple-touch-icon.png` there, `og.png` as `og-revived.png`, and `emblem-128.png` and
`logo-400` and `logo-800` (PNG and WebP) in `docs/assets/brand/`. Never edit those copies by hand.

The site's theme uses the palette like this:

- `docs/_sass/custom/setup.scss` defines the eight tokens (`$dr-ink` to `$dr-frost`), the only place
  the site sets a brand colour. `docs/_includes/head_custom.html` repeats `ink` once, as the browser's
  `theme-color`; `--check` compares both with `palette.json`.
- `docs/_sass/color_schemes/revived.scss` is the just-the-docs colour scheme (`color_scheme: revived`
  in `docs/_config.yml`) and the code highlighting, in frost, glow, steel and ice only.
- `docs/_sass/custom/custom.scss` covers what the scheme variables do not: button text, focus rings,
  the current page in the navigation, the header emblem, the home page logo, and printing (`ink`
  text and `azure` links on white paper, 20.07 and 6.18).
- The header shows the emblem and the site name (`docs/_includes/title.html`). The English and Finnish
  home pages show the full logo above their text (`docs/_includes/home_logo.html`).

README badges use `azure` (`0D669C`) with a `navy` (`031523`) label: shields.io draws white text,
which fails on `ice` (2.75) but passes on `azure` (6.18).

Small sizes: at 16 and 24 px the spikes of the emblem merge, and what remains is its outline, the
white skull and the cyan eye. Every emblem size of 48 px and below is resampled from the master with
a light sharpen and an alpha curve that keeps the outline crisp (stronger at 32 px and below); the
art is not redrawn.

### The launcher

The launcher uses copies: `npm run icon` in `UndauntedLauncher` copies `launcher/icon.ico` and
`launcher/icon-256.png` to its `assets/` (as `icon.ico` and `icon.png`), and the in-app logo and the
32, 64 and 512 px emblems to `src/renderer/brand/`. Its unit tests fail when a copy is out of date,
so run it after `build.py` changes one of them.

Its theme (`UndauntedLauncher/src/renderer/styles.css`) defines the eight tokens as `--dr-ink` to
`--dr-frost` and uses them like the docs site: an `ink` page with `navy` and `deep` surfaces,
`frost` text and `steel` muted text, `ice` links, primary buttons in `ink` on `ice` (`ink` on `glow`
hovered, `frost` on `azure` pressed), `glow` focus rings, and `steel` edges on controls on `navy`. The
palette has no red or amber, so warnings and problems are told apart by their icon, a bar on the left
edge and a brighter edge: `ice` for a warning, `glow` for a problem. A risky button (log out, trust a
changed certificate) is `frost` with a `frost` edge and a warning sign, never the inviting primary
style. The unit tests check that the stylesheet has no colour except the tokens and that every pair it
uses passes AA. Without a host's art pack the window shows an original night scene in the style of the
logo, drawn by `src/renderer/scene.ts`: jagged mountains with snow, a pine forest, mist, a faint
aurora, stars, falling snow and the emblem faded into the sky.

On top of it, `src/renderer/dauntless-style.css` dresses the launcher like the game's own menus:
steel frames, the game's bevelled blue bars, a gold PLAY and a gold news marker. The colours it needs
beyond the eight (steel greys, golds and the game's blues) are defined once there as `--dl-*` tokens;
`styles.css` keeps using only the palette.

## Rebuilding

`build.py` needs Python 3.10 or later, Pillow 9.1 or later with WebP support, `rsvg-convert`, and
the Inter and JetBrains Mono fonts (the banner and social preview text). Pillow also needs
libimagequant for the 256-colour web PNGs; without it they come out lossless and larger, so the
rebuilt files differ from the committed ones. On Debian or Ubuntu, including WSL (Ubuntu 22.04's
Pillow is too old):

```sh
sudo apt install python3-pil librsvg2-bin fonts-inter fonts-jetbrains-mono
python3 brand/build.py
```

To replace the artwork, pass the new files and the script copies them in as the masters (pixels kept
exactly, metadata chunks dropped) before it rebuilds:

```sh
python3 brand/build.py --import-masters new-logo.png new-emblem.png
```

The banner and social preview layouts, including their text, are SVG templates inside `build.py`.
Web PNGs of 128 px and up are 256-colour palette PNGs (libimagequant), about a third of the lossless
size with no visible difference; the masters, the launcher icons and the small emblems stay lossless.
